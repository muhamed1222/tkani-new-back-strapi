# 🐛 Настройка Sentry для мониторинга ошибок

## 📋 Что такое Sentry?

Sentry - это платформа для мониторинга ошибок в реальном времени. Она автоматически отслеживает:
- Ошибки приложения
- Производительность запросов
- SQL запросы
- Трейсинг запросов

---

## 🔧 Шаг 1: Создание аккаунта Sentry

1. Перейдите на https://sentry.io
2. Зарегистрируйтесь или войдите
3. Создайте новый проект:
   - Выберите **Python** как платформу
   - Выберите **Flask** как фреймворк
   - Назовите проект (например, "Tkani Backend")

---

## 🔧 Шаг 2: Получение DSN

После создания проекта вы получите **DSN** (Data Source Name). Он выглядит так:

```
https://xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx@o1234567.ingest.sentry.io/1234567
```

**Важно:** Сохраните этот DSN - он понадобится для настройки.

---

## 🔧 Шаг 3: Настройка .env файла

Добавьте в `.env`:

```env
# Sentry (мониторинг ошибок)
SENTRY_DSN=https://xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx@o1234567.ingest.sentry.io/1234567
SENTRY_ENVIRONMENT=production
```

**Важно:** 
- Замените DSN на ваш реальный DSN
- `SENTRY_ENVIRONMENT` может быть: `development`, `staging`, `production`

---

## 🔧 Шаг 4: Проверка установки

Sentry SDK уже установлен (в requirements.txt). Проверьте:

```bash
python3 -c "import sentry_sdk; print('✅ Sentry SDK установлен')"
```

---

## 🔧 Шаг 5: Тестирование

### 5.1. Создайте тестовую ошибку

Временно добавьте в код (например, в `app.py`):

```python
# Только для тестирования!
@app.route('/test-sentry')
def test_sentry():
    raise Exception("Тестовая ошибка для Sentry")
    return "OK"
```

### 5.2. Запустите приложение

```bash
python3 app.py
```

### 5.3. Откройте тестовый endpoint

```bash
curl http://localhost:5001/test-sentry
```

### 5.4. Проверьте Sentry

Зайдите в Sentry Dashboard - вы должны увидеть ошибку через несколько секунд.

**Важно:** Удалите тестовый endpoint после проверки!

---

## 📊 Что отслеживает Sentry

### Автоматически отслеживается:

1. **Необработанные исключения**
   - Все ошибки Python
   - Stack traces
   - Контекст выполнения

2. **Производительность**
   - Время выполнения запросов
   - Медленные запросы
   - SQL запросы

3. **Контекст**
   - Пользователь (если настроено)
   - Запросы и ответы
   - Переменные окружения (если разрешено)

### Настройки в коде:

Sentry уже настроен в `app.py` с оптимальными параметрами:
- Трейсинг 10% запросов (для экономии)
- Защита персональных данных (`send_default_pii=False`)
- Интеграция с Flask и SQLAlchemy

---

## 🔧 Дополнительная настройка

### Настройка уровней логирования

В `.env` можно добавить:

```env
# Уровень логирования для Sentry
SENTRY_LOG_LEVEL=ERROR  # ERROR, WARNING, INFO
```

### Настройка sample rate

В `app.py` можно изменить `traces_sample_rate`:

```python
sentry_sdk.init(
    dsn=sentry_dsn,
    traces_sample_rate=0.1,  # 10% запросов (измените на нужное значение)
    # ...
)
```

### Добавление пользовательского контекста

В коде можно добавить информацию о пользователе:

```python
from sentry_sdk import set_user

# В роуте после аутентификации
set_user({
    "id": user.id,
    "email": user.email,
    "username": user.first_name
})
```

## 📊 Использование Sentry Dashboard

### Основные разделы:

1. **Issues** - список ошибок
   - Группировка похожих ошибок
   - Статистика по ошибкам
   - История ошибок

2. **Performance** - производительность
   - Медленные запросы
   - Время ответа
   - Транзакции

3. **Releases** - релизы
   - Отслеживание версий
   - Связь ошибок с версиями

4. **Alerts** - уведомления
   - Email уведомления
   - Slack интеграция
   - Webhooks

---

## 🔔 Настройка уведомлений

### Email уведомления:

1. В Sentry Dashboard: Settings → Notifications
2. Настройте правила уведомлений
3. Выберите события для уведомлений

### Slack интеграция:

1. Settings → Integrations → Slack
2. Подключите Slack workspace
3. Настройте каналы для уведомлений

## ⚠️ Важные замечания

1. **Персональные данные:**
   - Sentry настроен с `send_default_pii=False`
   - Не отправляйте пароли, токены, кредитные карты
   - Используйте фильтры для чувствительных данных

2. **Производительность:**
   - `traces_sample_rate=0.1` означает 10% запросов
   - Увеличьте для более детального мониторинга
   - Уменьшите для экономии квоты

3. **Квота:**
   - Бесплатный план: 5,000 событий/месяц
   - Следите за использованием в Dashboard

## 🆘 Решение проблем

### Ошибки не появляются в Sentry

Проверьте:
1. Правильность DSN в `.env`
2. Что Sentry SDK инициализирован (проверьте логи)
3. Что приложение запущено с правильными переменными окружения

### Слишком много событий

Уменьшите `traces_sample_rate` или настройте фильтры в Sentry Dashboard.

### Персональные данные в Sentry

Настройте фильтры в Sentry Dashboard: Settings → Security & Privacy → Data Scrubbing
