# 📦 Настройка СДЭК API

## 🔑 Где получить данные для СДЭК

Для работы с API СДЭК нужны два параметра:
- **CDEK_ACCOUNT** (Account) - идентификатор аккаунта
- **CDEK_SECURE_PASSWORD** (Secure Password) - секретный пароль

## 📋 Как получить данные

### Шаг 1: Регистрация в СДЭК

1. Перейдите на сайт СДЭК: https://www.cdek.ru/
2. Зарегистрируйтесь или войдите в личный кабинет
3. Перейдите в раздел **"API"** или **"Интеграции"**

### Шаг 2: Создание API ключей

1. В личном кабинете найдите раздел **"API"** или **"Настройки интеграций"**
2. Создайте новое приложение/интеграцию
3. Система выдаст вам:
   - **Account** (идентификатор аккаунта)
   - **Secure Password** (секретный пароль)

### Шаг 3: Типы аккаунтов СДЭК

**Тестовый аккаунт (Test):**
- Для разработки и тестирования
- Бесплатный
- Ограниченный функционал

**Боевой аккаунт (Production):**
- Для реальных заказов
- Требует договора с СДЭК
- Полный функционал

## 🔧 Добавление в .env

После получения данных добавьте их в файл `.env`:

```env
# СДЭК
CDEK_ACCOUNT=ваш_account_идентификатор
CDEK_SECURE_PASSWORD=ваш_secure_password
CDEK_API_URL=https://api.cdek.ru/v2
```

## ✅ Проверка подключения

После добавления данных можно проверить подключение:

```bash
python3 test_cdek.py
```

Скрипт проверит:
- ✅ Получение токена авторизации
- ✅ Поиск городов
- ✅ Расчет стоимости доставки

## 📝 Формат данных

**CDEK_ACCOUNT:**
- Обычно строка из букв и цифр
- Пример: `z9ej0U1hALLkBv9BH6b5ftE9XF9gABPc`

**CDEK_SECURE_PASSWORD:**
- Секретная строка
- Пример: `dwzH2jJN8khObxbTlVg04Pvj8easpznT`

## ⚠️ Важно

- **Не публикуйте** эти ключи в открытом доступе
- **Храните** их только в `.env` файле (который в `.gitignore`)
- **Используйте** тестовый аккаунт для разработки
- **Переключитесь** на боевой аккаунт перед запуском в production

## 🆘 Если нет доступа к API

Если у вас еще нет доступа к API СДЭК:

1. **Свяжитесь с СДЭК:**
   - Через форму на сайте
   - По телефону поддержки
   - Через личный кабинет

2. **Запросите доступ к API:**
   - Укажите, что нужен доступ для интеграции
   - Вам предоставят Account и Secure Password

3. **Для тестирования:**
   - Можно использовать расчетную стоимость доставки
   - Система автоматически использует расчет, если API недоступен
