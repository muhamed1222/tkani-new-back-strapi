# 🤖 АВТОМАТИЧЕСКАЯ НАСТРОЙКА PERMISSIONS

## Я ОТКРЫЛ STRAPI ADMIN ДЛЯ ВАС! ✅

Теперь выполните эти простые шаги вручную:

### Шаг 1: Перейдите к Roles
В Strapi Admin (который уже открыт), найдите в левом меню:
**Settings → Users & Permissions plugin → Roles**

Или откройте напрямую:
http://localhost:1337/admin/settings/users-permissions/roles

### Шаг 2: Откройте роль Authenticated
Нажмите на роль **"Authenticated"**

### Шаг 3: Включите permissions

Найдите и включите следующие разделы (галочки):

#### ✅ CART
- [x] find
- [x] findOne  
- [x] create
- [x] update
- [x] delete
- [x] addToCart
- [x] getCart
- [x] updateCart
- [x] removeFromCart
- [x] clearCart

#### ✅ ORDER  
- [x] find
- [x] findOne
- [x] create
- [x] update

#### ✅ PAYMENT
- [x] init
- [x] checkStatus

### Шаг 4: Сохраните
Нажмите кнопку **"Save"** в правом верхнем углу

## 🎯 ГОТОВО!

После сохранения permissions, можно переходить к тестированию!
