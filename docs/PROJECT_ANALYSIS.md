# 📊 Анализ проекта Tkani

## 📋 Общая информация

**Название:** Tkani - Интернет-магазин тканей  
**Тип:** Full-stack приложение (Frontend + Backend + CMS)  
**Статус:** Готов к продакшену ✅

---

## 🏗 Архитектура проекта

### Структура:
```
tkani-new-main/          # Frontend (React + Vite)
tkani-new-back-strapi/   # Backend (Flask) + CMS (Strapi)
```

### Компоненты:
1. **Frontend** - React 19 приложение
2. **Backend API** - Flask REST API
3. **CMS** - Strapi 5.31 для управления контентом
4. **База данных** - SQLite (dev) / PostgreSQL (production)

## 🔌 API Endpoints

### Аутентификация:
- ✅ POST `/api/v1/auth/register` - Регистрация
- ✅ POST `/api/v1/auth/login` - Вход
- ✅ GET `/api/v1/auth/me` - Текущий пользователь
- ✅ PUT `/api/v1/auth/update` - Обновить профиль
- ✅ POST `/api/v1/auth/change-password` - Изменить пароль
- ✅ POST `/api/v1/auth/forgot-password` - Восстановление пароля
- ✅ POST `/api/v1/auth/reset-password` - Сброс пароля

### Каталог:
- ✅ GET `/api/v1/catalog/products` - Список товаров
- ✅ GET `/api/v1/catalog/products/:id` - Детали товара
- ✅ GET `/api/v1/catalog/categories` - Категории
- ✅ GET `/api/v1/catalog/brands` - Бренды

### Корзина:
- ✅ GET `/api/v1/cart/` - Получить корзину
- ✅ POST `/api/v1/cart/add` - Добавить товар
- ✅ POST `/api/v1/cart/update` - Обновить количество
- ✅ POST `/api/v1/cart/remove` - Удалить товар
- ✅ POST `/api/v1/cart/clear` - Очистить корзину

### Заказы:
- ✅ POST `/api/v1/orders/create` - Создать заказ
- ✅ GET `/api/v1/orders/my` - Мои заказы
- ✅ GET `/api/v1/orders/:id` - Детали заказа

### Платежи:
- ✅ POST `/api/v1/payment/yoomoney/create` - Создать платеж
- ✅ POST `/api/v1/payment/yoomoney/callback` - Webhook от ЮKassa

### Доставка:
- ✅ POST `/api/v1/delivery/calculate` - Рассчитать стоимость
