## 📋 Использование

API автоматически используется при выборе доставки "Почта России" в заказе.

### Расчет стоимости доставки

```bash
POST /api/v1/delivery/calculate
```

**Тело запроса:**
```json
{
  "provider": "russian_post",
  "weight": 1.5,
  "dimensions": {
    "length": 30,
    "width": 20,
    "height": 10
  },
  "from_city": "Нальчик",
  "to_city": "Москва",
  "to_address": "ул. Примерная, д. 1"
}
```

**Ответ:**
```json
{
  "success": true,
  "provider": "russian_post",
  "cost": 190.0,
  "currency": "RUB"
}
```

## 🔍 Как это работает

1. При расчете стоимости доставки система пытается использовать реальный API Почты России
2. Если API недоступен или не вернул результат, используется расчетная стоимость на основе параметров
3. Расчетная стоимость учитывает:
   - Вес посылки
   - Объем посылки
   - Расстояние между городами

## ⚙️ Технические детали

- **API URL:** `https://otpravka-api.pochta.ru`
- **Авторизация:** `Authorization: AccessToken {token}`
- **Endpoint для расчета:** `/1.0/tariff`
- **Формат веса:** граммы (целое число)
- **Тип посылки:** 27030 (стандартная посылка)

## 🆘 Решение проблем

### API не возвращает стоимость

Если API не работает, система автоматически использует расчетную стоимость на основе:
- Базовой стоимости: 190₽ (до 2 кг)
- Надбавка за вес: +30₽ за каждый кг свыше 2 кг
- Надбавка за объем: если объем > 0.05 м³
- Надбавка за расстояние: для региональной доставки

### Проверка работы API

Проверьте логи приложения при расчете доставки. Если API работает, вы увидите успешные запросы. Если нет - будут предупреждения и будет использована расчетная стоимость.
