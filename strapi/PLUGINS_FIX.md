# Исправление проблемы с загрузкой плагинов

## Проблема
При запуске `npm run develop` возникала ошибка:
```
Error: Error loading the plugin audit-log because audit-log is not installed.
```

## Решение

В Strapi v5 кастомные плагины, расположенные в `src/plugins/`, **автоматически загружаются** и **не требуют** явной конфигурации в `config/plugins.js`.

### Что было исправлено:

1. **Добавлены entry points в package.json** для всех кастомных плагинов:
   - `main`: путь к server entry point
   - `strapi.admin.main`: путь к admin entry point

2. **Убрана конфигурация кастомных плагинов из config/plugins.js**:
   - Кастомные плагины загружаются автоматически
   - Конфигурация доступна через `strapi.config.get('plugin.plugin-name')` или через переменные окружения

3. **Обновлены bootstrap функции**:
   - Используют дефолтные значения вместо конфигурации из config/plugins.js
   - Конфигурация может быть переопределена через переменные окружения

## Текущая структура config/plugins.js

Теперь в `config/plugins.js` остались только **встроенные плагины**:
- `users-permissions`
- `upload`
- `email`

Кастомные плагины (audit-log, seo, orders, payments) загружаются автоматически из `src/plugins/`.

## Конфигурация кастомных плагинов

Для настройки кастомных плагинов используйте:

1. **Переменные окружения** (рекомендуется)
2. **Bootstrap функции** в каждом плагине
3. **Прямой доступ** через `strapi.config.get('plugin.plugin-name')` в коде
