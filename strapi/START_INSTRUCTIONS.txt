❌ ПРОБЛЕМА:
Вы запускаете npm run develop из КОРНЕВОЙ директории,
но package.json находится в директории strapi/

✅ РЕШЕНИЕ:

1. Запустите Strapi (должно быть из директории strapi/):

   cd strapi
   npm run develop

   ИЛИ используйте скрипт:
   
   ./start_strapi.sh

2. Если Flask не запускается (порт 5001 занят):

   # Найдите и остановите процесс
   lsof -ti:5001 | xargs kill -9
   
   # Затем запустите Flask
   python3 app.py
