# Исправление обновления профиля (403 Forbidden на PUT запросе)

## Проблема
После успешной загрузки файла возникает ошибка `403 Forbidden` на PUT запросе при попытке обновить профиль пользователя.

## Причина
Код пытался обновить профиль через `/api/users/:id`, но в Strapi по умолчанию пользователи не имеют прав на обновление через этот endpoint.

## Решение

### 1. Использование кастомного endpoint `/api/profile`

В проекте уже есть кастомный endpoint `/api/profile`, который специально создан для обновления профиля аутентифицированными пользователями.

### 2. Изменения в коде

#### Backend (strapi/src/api/profile/controllers/profile.js):
- ✅ Добавлена поддержка поля `avatar` в контроллере
- ✅ Добавлен `avatar` в populate для получения полных данных

#### Frontend (src/http/auth.js):
- ✅ Изменен endpoint с `/api/users/:id` на `/api/profile`
- ✅ Убрана необходимость получать ID пользователя отдельно

### 3. Проверка прав доступа

Endpoint `/api/profile` уже настроен с правильной авторизацией:
- Использует JWT стратегию
- Требует scope `authenticated`
- Позволяет пользователям обновлять только свой профиль

## Что нужно сделать

### Если все еще получаете 403:

1. **Проверьте права на API Profile:**
   - Откройте Strapi Admin: `http://localhost:1337/admin`
   - Settings → Users & Permissions plugin → Roles
   - Выберите роль **Authenticated**
   - Найдите раздел **"Profile"** (api::profile)
   - Включите права:
     - ✅ **update** (обновление профиля)
   - Нажмите **Save**

2. **Перезапустите Strapi:**
   ```bash
   # Остановите (Ctrl+C) и запустите снова
   npm run develop
   ```

3. **Проверьте логи:**
   - В консоли Strapi должны появиться логи:
     - `🔄 Обновление профиля - начало`
     - `📝 Новые данные: {...}`
     - `✅ Профиль успешно обновлен`

## Проверка работы

После исправлений:
1. Попробуйте загрузить аватар снова
2. В консоли браузера должно быть:
   - `POST /api/upload` → `200 OK` (загрузка файла)
   - `PUT /api/profile` → `200 OK` (обновление профиля)
3. Аватар должен успешно обновиться

## Измененные файлы

1. `strapi/src/api/profile/controllers/profile.js` - добавлена поддержка avatar
2. `src/http/auth.js` - изменен endpoint на `/api/profile`
