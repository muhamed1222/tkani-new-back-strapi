# Пошаговая инструкция: Настройка прав для загрузки файлов

## Проблема
Ошибка `403 Forbidden` при загрузке аватара. В интерфейсе прав не видно раздела "Upload".

## Решение

### Где искать права для upload?

**"Upload" находится в разделе "Media Library" (Библиотека медиафайлов)**

В Strapi Admin Panel есть два разных раздела:
1. **Plugins** (Плагины) - здесь находится "Media Library" = `plugin::upload`
2. **API** (API endpoints) - здесь находятся api::banner, api::cart и т.д. (upload здесь НЕТ)

### Пошаговая инструкция:

1. **Откройте Strapi Admin Panel**
   ```
   http://localhost:1337/admin
   ```

2. **Перейдите в настройки прав:**
   - Нажмите на иконку ⚙️ **Settings** (в левом меню внизу)
   - Выберите **Users & Permissions plugin**
   - Выберите **Roles** (Роли)

3. **Выберите роль:**
   - Найдите и нажмите на роль **Authenticated** (Аутентифицированный)
   - Или на роль, которую использует ваш пользователь

4. **Найдите раздел "Media Library":**
   - Прокрутите список вниз
   - Найдите раздел **"Media Library"** 
   - Под ним будет подпись: "Определите все разрешенные действия для плагина **plugin::upload**"
   - ⚠️ **Это НЕ в разделе API endpoints!** Это в разделе **Plugins**

5. **Раскройте раздел "Media Library":**
   - Нажмите на стрелку ▼ справа от "Media Library"
   - Откроется список действий

6. **Включите необходимые права:**
   - ✅ Поставьте галочку на **create** (создание/загрузка файлов)
   - ✅ Поставьте галочку на **read** (чтение файлов)
   - ✅ Поставьте галочку на **update** (обновление файлов)
   - ⚪ **delete** (удаление) - опционально

7. **Сохраните изменения:**
   - Нажмите кнопку **Save** (Сохранить) вверху страницы

8. **Перезапустите Strapi:**
   ```bash
   # Остановите Strapi (Ctrl+C)
   # Запустите снова
   npm run develop
   ```

### Проверка:

После настройки:
1. Перезапустите Strapi
2. Попробуйте загрузить аватар снова
3. В консоли браузера должно быть `200 OK` вместо `403 Forbidden`

### Если все еще не работает:

1. Проверьте, что вы сохранили изменения (кнопка Save)
2. Убедитесь, что перезапустили Strapi
3. Проверьте токен авторизации в DevTools → Network → Headers
4. Проверьте логи Strapi сервера на наличие ошибок
