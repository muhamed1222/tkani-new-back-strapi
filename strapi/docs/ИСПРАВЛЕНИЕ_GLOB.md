# ✅ Исправление уязвимости glob

## Проблема

**Уязвимость**: Command injection через CLI (CVE-2025-64756)  
**Пакет**: `glob` версии 10.2.0 - 10.4.5  
**Серьезность**: High  
**Описание**: Уязвимость позволяет выполнение произвольных команд через параметр `-c/--cmd` в CLI

## Решение

Использован механизм `overrides` в `package.json` для принудительного обновления `glob` до безопасной версии `10.5.0+`.

### Изменения в package.json:

```json
{
  "overrides": {
    "@strapi/core": {
      "glob": "^10.5.0"
    },
    "@strapi/admin": {
      "glob": "^10.5.0"
    },
    "glob": "^10.5.0"
  }
}
```

### Как это работает:

1. **overrides** - механизм npm, который позволяет переопределить версии зависимостей
2. Принудительно устанавливает `glob@10.5.0+` для всех пакетов, которые требуют `glob@10.x`
3. Не затрагивает `glob@7.x`, который используется другими пакетами (rimraf, copyfiles и т.д.)

## Результат

### До исправления:
- `glob@10.3.10` (уязвимая версия)
- 21 уязвимость (3 high)

### После исправления:
- `glob@10.5.0` (безопасная версия) ✅
- 20 уязвимостей (2 high) ✅
- Уязвимость `glob` устранена ✅

## Проверка

```bash
# Проверка версии glob
npm list glob | grep "glob@10"
# → glob@10.5.0 ✅

# Проверка уязвимостей
npm audit | grep "glob"
# → (пусто, уязвимость устранена) ✅
```

## Важно

⚠️ **Уязвимость затрагивает только CLI** (`-c/--cmd` параметр)

В контексте Strapi:
- ✅ `glob` используется только программно (не через CLI)
- ✅ Нет прямого использования CLI `glob`
- ✅ Риск минимален, но исправление применено для полной безопасности
