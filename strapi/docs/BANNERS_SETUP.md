# Настройка баннеров для слайдеров

## Описание

Создана новая коллекция **Banner** в Strapi для управления баннерами слайдеров на главной странице сайта.

## Структура Content Type

### Поля:

1. **image** (Media - Image)
   - Изображение баннера
   - Обязательное поле
   - Тип: одно изображение

2. **title** (JSON)
   - Заголовок баннера
   - Может быть массивом строк (например: `["ТКАНИ ДЛЯ", "ОДЕЖДЫ"]`)
   - Или строкой с переносами строк
   - Необязательное поле

3. **textPosition** (Enumeration)
   - Позиция текста на баннере
   - Варианты: `left` или `right`
   - По умолчанию: `left`
   - Обязательное поле

4. **section** (Enumeration)
   - Раздел баннера
   - Варианты: `clothing` (Для одежды) или `home` (Для дома)
   - По умолчанию: `clothing`
   - Обязательное поле

5. **order** (Integer)
   - Порядок сортировки баннеров
   - По умолчанию: `0`
   - Минимальное значение: `0`
   - Используется для сортировки баннеров в слайдере

## Использование

### Добавление баннера:

1. Перейдите в Strapi Admin панель: `http://localhost:1337/admin`
2. Откройте раздел **Content Manager** → **Banner**
3. Нажмите **Create new entry**
4. Заполните поля:
   - **Image**: Загрузите изображение баннера
   - **Title**: Введите заголовок (можно использовать JSON формат для многострочного текста)
   - **Text Position**: Выберите `left` или `right`
   - **Section**: Выберите `clothing` (для левого слайдера) или `home` (для правого слайдера)
   - **Order**: Укажите порядок (0, 1, 2, 3...)
5. Нажмите **Save** и затем **Publish**

### Примеры данных:

#### Для левого слайдера (clothing):
- **Image**: `/LeftSlider/IMG1.JPG`
- **Title**: `["ТКАНИ ДЛЯ", "ОДЕЖДЫ"]` (в формате JSON)
- **Text Position**: `left`
- **Section**: `clothing`
- **Order**: `0`

#### Для правого слайдера (home):
- **Image**: `/RightSlider/IMG1.PNG`
- **Title**: `["ТКАНИ ДЛЯ", "ДОМА"]` (в формате JSON)
- **Text Position**: `right`
- **Section**: `home`
- **Order**: `0`

## API Endpoints

### Получить все баннеры:
```
GET /api/banners?populate=*
```

### Получить баннеры для раздела "Для одежды":
```
GET /api/banners?filters[section][$eq]=clothing&populate=*&sort=order:asc
```

### Получить баннеры для раздела "Для дома":
```
GET /api/banners?filters[section][$eq]=home&populate=*&sort=order:asc
```

## Интеграция с фронтендом

Баннеры автоматически загружаются на главной странице через `TkanStore.fetchBanners()`.

Компонент `Shop.jsx` использует баннеры из Strapi с fallback на статические данные, если баннеры еще не загружены.

## Важные замечания

1. **Порядок баннеров**: Баннеры сортируются по полю `order` в порядке возрастания
2. **Публикация**: Убедитесь, что баннеры опубликованы (Published), иначе они не будут отображаться на фронтенде
3. **Формат заголовка**: Заголовок может быть:
   - Массивом строк в JSON: `["ТКАНИ ДЛЯ", "ОДЕЖДЫ"]`
   - Строкой с переносами: `"ТКАНИ ДЛЯ\nОДЕЖДЫ"`
4. **Изображения**: Рекомендуется использовать изображения одинакового размера для лучшего отображения в слайдере
