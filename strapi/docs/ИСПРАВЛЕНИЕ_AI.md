# ✅ Исправление уязвимости AI SDK (Vercel)

## Проблема

**Уязвимость**: Обход whitelist типов файлов при загрузке (CVE-2025-48985)  
**Пакет**: `ai` (Vercel AI SDK) версии <5.0.52  
**Серьезность**: High  
**Описание**: Уязвимость позволяет обойти валидацию типов файлов в SDK, заменяя произвольные загруженные байты на разные поддерживаемые URL в одном промпте.

## Решение

Применено три уровня защиты:

### 1. Обновление ai до безопасной версии

Использован механизм `overrides` в `package.json` для принудительного обновления `ai` до версии `5.0.52+`.

```json
{
  "overrides": {
    "@strapi/content-type-builder": {
      "ai": "^5.0.52",
      "@ai-sdk/react": {
        "ai": "^5.0.52"
      }
    },
    "ai": "^5.0.52",
    "@ai-sdk/react": {
      "ai": "^5.0.52"
    }
  }
}
```

### 2. Middleware для валидации файлов

Создан кастомный middleware `file-validation.js`, который:

- ✅ **Валидирует MIME типы**: Проверяет, что загружаемый файл имеет разрешенный MIME тип
- ✅ **Валидирует расширения**: Проверяет расширение файла
- ✅ **Проверяет соответствие**: Убеждается, что MIME тип соответствует расширению
- ✅ **Логирует попытки**: Записывает в лог попытки загрузки небезопасных файлов
- ✅ **Блокирует небезопасные файлы**: Отклоняет загрузку файлов, не прошедших валидацию

### 3. Конфигурация Upload Plugin

Добавлена дополнительная валидация в `config/plugins.js`:

```javascript
upload: {
  config: {
    allowedFileTypes: [...], // Список разрешенных MIME типов
    allowedExtensions: [...], // Список разрешенных расширений
  },
}
```

## Разрешенные типы файлов

### MIME типы:
- `image/jpeg`, `image/jpg`, `image/png`, `image/gif`, `image/webp`, `image/svg+xml`
- `application/pdf`
- `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
- `application/vnd.ms-excel`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

### Расширения:
- `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg`
- `.pdf`
- `.doc`, `.docx`, `.xls`, `.xlsx`

## Настройка для production

1. **Обновите список разрешенных типов файлов** в `file-validation.js` и `config/plugins.js`, если нужны дополнительные типы

2. **Настройте размер файлов** в `config/plugins.js`:
   ```javascript
   sizeLimit: 250 * 1024 * 1024, // 250MB
   ```

3. **Используйте сканирование на вирусы** (опционально):
   - Интегрируйте антивирусное сканирование перед сохранением файлов
   - Используйте сервисы типа ClamAV или VirusTotal API

4. **Мониторинг**:
   - Следите за логами попыток загрузки небезопасных файлов
   - Настройте алерты на подозрительную активность
