# Инструкция по настройке корзины для неавторизованных пользователей

## Проблема: 403 Forbidden при добавлении товаров в корзину

### Решение 1: Настройка через Admin Panel (РЕКОМЕНДУЕТСЯ)

1. **Запустите Strapi:**
   ```bash
   cd strapi
   npm run develop
   ```

2. **Откройте Admin Panel:**
   - Перейдите: http://localhost:1337/admin
   - Войдите под администратором

3. **Настройте Permissions:**
   - Перейдите: **Settings** → **Users & Permissions Plugin** → **Roles**
   - Нажмите на роль **"Public"**
   - Найдите секцию **"Cart"**
   - Включите следующие permissions:
     - ✅ `find` - получение корзины
     - ✅ `findOne` - получение одной корзины
     - ✅ `create` - создание корзины
     - ✅ `update` - обновление корзины
   - Нажмите **"Save"** в правом верхнем углу

### Решение 2: Автоматическая настройка (через bootstrap)

Код в `src/index.js` автоматически настроит permissions при запуске Strapi.

### Как проверить работу:

1. **Откройте браузер в режиме инкогнито** (без авторизации)
2. **Откройте DevTools** → **Network**
3. **Попробуйте добавить товар в корзину**
4. **Проверьте:**
   - Запрос отправляется с заголовком `X-Session-Id` (если есть cookie)
   - В ответе устанавливается cookie `cart_session_id`
   - Нет ошибки 403 Forbidden

### Если все еще не работает:

1. **Проверьте логи Strapi** при попытке добавить товар
2. **Проверьте, что Strapi перезапущен** после изменений
3. **Проверьте permissions в Admin Panel** (Решение 1)
4. **Проверьте консоль браузера** на ошибки CORS
