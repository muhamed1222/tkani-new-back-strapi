# Руководство по планшетной версии админ-панели Strapi

## Обзор

В админ-панели Strapi добавлена полная поддержка планшетной версии (768px - 1024px) с оптимизацией для тач-интерфейса.

## Breakpoints

### Планшеты
- **Портретная ориентация**: 768px - 900px
- **Альбомная ориентация**: 900px - 1024px

### Мобильные устройства
- **До 768px**: Мобильная версия (базовая поддержка Strapi)

### Десктопы
- **Свыше 1024px**: Полная версия

## Реализованные улучшения

### 1. Боковое меню
- **Планшеты**: Ширина уменьшена до 200px (портрет) / 180px (альбом)
- **Адаптивное поведение**: Автоматическая корректировка отступов контента

### 2. Типографика
- **Заголовки**: Оптимизированы размеры для планшетов
  - H1: 24px (вместо 32px)
  - H2: 20px (вместо 24px)
  - H3: 18px (вместо 20px)

### 3. Таблицы
- **Адаптивная ширина**: Автоматическая прокрутка на маленьких экранах
- **Компактные отступы**: 8px-12px вместо стандартных
- **Размер шрифта**: 14px для лучшей читаемости

### 4. Формы
- **Оптимизированные поля**: Удобный размер для тач-интерфейса
- **Адаптивная ширина**: 100% на планшетах
- **Размер шрифта**: 14px

### 5. Кнопки
- **Минимальная высота**: 40px для удобного нажатия
- **Отступы**: 10px-16px
- **Размер шрифта**: 14px

### 6. Карточки
- **Компактные отступы**: 16px вместо 24px
- **Адаптивные сетки**: 2 колонки вместо 3-4

### 7. Модальные окна
- **Адаптивная ширина**: 90% экрана
- **Центрирование**: Автоматическое

### 8. Тач-интерфейс
- **Увеличенные области клика**: Минимум 44x44px
- **Улучшенный фокус**: Четкие индикаторы
- **Активные состояния**: Визуальная обратная связь при нажатии

## Использование утилит

### Импорт утилит
```javascript
import { 
  isTablet, 
  getBreakpoint, 
  onResize,
  getGridColumns 
} from './responsiveUtils';
```

### Проверка устройства
```javascript
if (isTablet()) {
  // Код для планшетов
}
```

### Отслеживание изменений размера
```javascript
const unsubscribe = onResize(({ breakpoint, width, height }) => {
  console.log(`Текущий breakpoint: ${breakpoint}`);
  console.log(`Размер: ${width}x${height}`);
});

// Отписка при размонтировании
// unsubscribe();
```

### Адаптивные сетки
```javascript
const columns = getGridColumns({
  mobile: 1,
  tablet: 2,
  desktop: 3
});
// Вернет 2 для планшетов
```

## CSS Медиа-запросы

Все стили находятся в `src/admin/customTheme.js` и применяются автоматически.

### Основные медиа-запросы:
```css
/* Планшеты */
@media screen and (min-width: 768px) and (max-width: 1024px) {
  /* Стили для планшетов */
}

/* Портретная ориентация */
@media screen and (min-width: 768px) and (max-width: 900px) {
  /* Компактные стили */
}

/* Альбомная ориентация */
@media screen and (min-width: 900px) and (max-width: 1024px) {
  /* Оптимизированные стили */
}

/* Тач-интерфейс */
@media screen and (min-width: 768px) and (max-width: 1024px) and (hover: none) {
  /* Стили для тач-устройств */
}
```

## Дополнительные улучшения

### Для разработчиков плагинов:

При создании кастомных компонентов используйте утилиты:

```javascript
import { getBreakpoint, getResponsivePadding } from '../../admin/responsiveUtils';

const MyComponent = () => {
  const breakpoint = getBreakpoint();
  const padding = getResponsivePadding({
    mobile: '8px',
    tablet: '16px',
    desktop: '24px'
  });
  
  return (
    <div style={{ padding }}>
      {/* Контент */}
    </div>
  );
};
```

## Известные ограничения

1. **Strapi 5**: Некоторые компоненты могут иметь собственные стили, которые переопределяют наши
2. **Кастомные плагины**: Требуют дополнительной адаптации
3. **Старые браузеры**: Могут не поддерживать некоторые CSS-свойства

## Обновления

Все изменения находятся в:
- `src/admin/customTheme.js` - Адаптивные стили
- `src/admin/responsiveUtils.js` - Утилиты для работы с адаптивностью

## Поддержка

При возникновении проблем с отображением на планшетах:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что стили применяются (проверьте в DevTools)
3. Проверьте, что используется актуальная версия Strapi
