# ✅ Исправление уязвимости tmp

## Проблема

**Уязвимость**: Позволяет запись в произвольные временные файлы через symbolic links (GHSA-52f5-9888-hmc6, CVE-2025-54798)  
**Пакет**: `tmp` версии <=0.2.3 (через `inquirer` → `external-editor`)  
**Серьезность**: Moderate  
**Описание**: Уязвимость позволяет запись в произвольные временные файлы или директории через symbolic link в параметре `dir`.

## Решение

Использован механизм `overrides` в `package.json` для принудительного обновления `tmp` до версии `0.2.4+` для всех зависимостей.

```json
{
  "overrides": {
    "@strapi/generators": {
      "tmp": "^0.2.4"
    },
    "inquirer": {
      "external-editor": {
        "tmp": "^0.2.4"
      },
      "tmp": "^0.2.4"
    },
    "external-editor": {
      "tmp": "^0.2.4"
    },
    "jscodeshift": {
      "tmp": "^0.2.4"
    },
    "tmp": "^0.2.4"
  }
}
```

## Результат

### До исправления:
- `tmp@0.0.33` через external-editor (уязвимая версия)
- `tmp@0.2.5` через jscodeshift (безопасная версия)
- 9 уязвимостей

### После исправления:
- `tmp@0.2.5` для всех зависимостей (безопасная версия) ✅
- 2 уязвимости ✅ (-7 уязвимостей!)
- Уязвимость tmp устранена ✅

## Дополнительные меры безопасности

Хотя уязвимость устранена, рекомендуется:

1. ✅ **Запускать Strapi от непривилегированного пользователя** (не root)
2. ✅ **Использовать изолированную файловую систему** (Docker контейнеры)
3. ✅ **Ограничить права доступа** к временным директориям
4. ✅ **Использовать chroot** для дополнительной изоляции (опционально)
