# Исправление ошибки Connection timeout при отправке email

## Проблема
Ошибка `Connection timeout` при попытке отправить тестовый email через Yandex Mail SMTP.

## Причины
1. Таймауты слишком короткие
2. Неправильный SMTP хост
3. Проблемы с портом 465 (может быть заблокирован)
4. Проблемы с сетью/файрволом

## Исправления

### 1. Увеличены таймауты в `config/plugins.js`

Таймауты увеличены для более стабильного соединения:
- `connectionTimeout: 30000` (30 секунд вместо 10)
- `greetingTimeout: 20000` (20 секунд вместо 10)
- `socketTimeout: 60000` (60 секунд вместо 10)

### 2. Рекомендуемые настройки для Yandex Mail

**Вариант 1: Порт 587 с STARTTLS (РЕКОМЕНДУЕТСЯ)**

Измените в `.env`:
```env
SMTP_HOST=smtp.yandex.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_EMAIL=centertkani-shop@yandex.ru
SMTP_PASS=ifjvlxwfkmzsfnnk
```

**Вариант 2: Порт 465 с SSL**

Если порт 587 не работает, попробуйте:
```env
SMTP_HOST=smtp.yandex.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_EMAIL=centertkani-shop@yandex.ru
SMTP_PASS=ifjvlxwfkmzsfnnk
```

**Важно:** Используйте `smtp.yandex.com` вместо `smtp.yandex.ru` - это официальный хост.

### 3. Включение debug режима

Для диагностики добавьте в `.env`:
```env
SMTP_DEBUG=true
```

Это включит подробные логи соединения.

### 4. Проверка доступности SMTP сервера

Проверьте, доступен ли SMTP сервер:

```bash
# Проверка порта 587
telnet smtp.yandex.com 587

# Или проверка порта 465
telnet smtp.yandex.com 465
```

Если соединение не устанавливается, возможно:
- Порт заблокирован файрволом
- Проблемы с интернет-соединением
- ISP блокирует SMTP порты

## Пошаговое решение

### Шаг 1: Измените настройки в `.env`

Попробуйте сначала порт 587:
```env
SMTP_HOST=smtp.yandex.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_EMAIL=centertkani-shop@yandex.ru
SMTP_PASS=ifjvlxwfkmzsfnnk
EMAIL_DEFAULT_FROM=centertkani-shop@yandex.ru
EMAIL_DEFAULT_REPLY_TO=centertkani-shop@yandex.ru
```

### Шаг 2: Перезапустите Strapi

```bash
npm run develop
```

### Шаг 3: Проверьте отправку email

1. Откройте админку: http://localhost:1337/admin
2. Settings → Email
3. Отправьте тестовый email

### Шаг 4: Если не работает - включите debug

Добавьте в `.env`:
```env
SMTP_DEBUG=true
```

Перезапустите Strapi и проверьте логи - там будет подробная информация о попытке соединения.

### Шаг 5: Альтернатива - порт 465

Если порт 587 не работает, попробуйте:
```env
SMTP_HOST=smtp.yandex.com
SMTP_PORT=465
SMTP_SECURE=true
```

## Проверка пароля приложения

Убедитесь, что используете **пароль приложения**, а не основной пароль:

1. Перейдите в [Настройки безопасности Yandex](https://id.yandex.ru/security)
2. Включите "Пароли приложений"
3. Создайте новый пароль для "Почта"
4. Используйте этот пароль в `SMTP_PASS`

## Возможные проблемы

### Проблема: Порт заблокирован файрволом

**Решение:** 
- Проверьте настройки файрвола
- Разрешите исходящие соединения на порты 587 и 465
- Если используете VPN, попробуйте отключить его

### Проблема: ISP блокирует SMTP

**Решение:**
- Некоторые провайдеры блокируют SMTP порты
- Попробуйте использовать другой интернет-канал
- Или используйте альтернативный SMTP сервис

### Проблема: Неправильный хост

**Решение:**
- Используйте `smtp.yandex.com` (не `.ru`)
- Проверьте, что домен email соответствует: `@yandex.ru` или `@yandex.com`
