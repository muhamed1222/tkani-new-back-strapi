# Решение проблемы: Orders не отображается в админке

## Проблема
Коллекция "Orders" не появляется в админ-панели Strapi после создания структуры.

## Решения

### 1. Перезапуск Strapi

После изменения схемы content types в Strapi v5 **обязательно** нужно перезапустить сервер:

```bash
# Остановите текущий процесс (Ctrl+C)
# Затем запустите снова:
npm run develop
```

### 2. Проверка структуры файлов

Убедитесь, что файлы находятся в правильных местах:

```
src/
├── api/
│   └── order/
│       └── content-types/
│           └── order/
│               └── schema.json      ✅ Должен существовать
└── components/
    └── order/
        └── order-item.json          ✅ Должен существовать
```

### 3. Проверка схемы

Убедитесь, что в `schema.json` есть:
- `"kind": "collectionType"`
- `"collectionName": "orders"`
- Правильные `info.singularName` и `info.pluralName`

### 4. Очистка кэша и пересборка

Если перезапуск не помог:

```bash
# Остановите Strapi
# Удалите кэш
rm -rf .cache
rm -rf build
rm -rf dist

# Перезапустите
npm run develop
```

### 5. Проверка компонента order-item

Убедитесь, что компонент `order.order-item` правильно настроен и загружается.

### 6. Проверка логов

При запуске Strapi проверьте логи на наличие ошибок:

```bash
npm run develop 2>&1 | grep -i "error\|order"
```

Должно быть:
```
✅ Order lifecycle hooks registered
```

Если есть ошибки - исправьте их.

### 7. Проверка в админке

После перезапуска:
1. Откройте админ-панель: http://localhost:1337/admin
2. Перейдите в **Content Manager**
3. В левом меню должна появиться коллекция **"Заказы"** (Orders)

### 8. Если все еще не работает

Проверьте, что:
- Нет синтаксических ошибок в JSON файлах
- Все обязательные поля заполнены
- Компонент `order.order-item` существует и правильно настроен
- Нет конфликтов имен с другими коллекциями

---

## Быстрое решение

1. **Остановите Strapi** (Ctrl+C в терминале)
2. **Очистите кэш:**
   ```bash
   rm -rf .cache build dist
   ```
3. **Запустите снова:**
   ```bash
   npm run develop
   ```
4. **Дождитесь полной загрузки** (должно быть сообщение "Strapi started successfully")
5. **Обновите страницу админки** (F5 или Cmd+R)

После этого коллекция "Orders" должна появиться в Content Manager.
