# ⚠️ Важно: Уязвимости в зависимостях

## Текущая ситуация

После выполнения `npm audit fix --force` были обнаружены уязвимости в зависимостях. **НЕ ИСПОЛЬЗУЙТЕ `npm audit fix --force`** без предварительной проверки!

## Почему `npm audit fix --force` опасен?

Команда `npm audit fix --force` может:
- ❌ Откатить версии пакетов на более старые (как произошло со Strapi: 5.31.3 → 4.26.0)
- ❌ Сломать совместимость с другими зависимостями
- ❌ Привести к breaking changes, которые сломают проект

## Текущие уязвимости

После восстановления правильной версии Strapi 5.31.3 осталось **25 уязвимостей**:
- 15 low (низкий приоритет)
- 5 moderate (средний приоритет)
- 3 high (высокий приоритет)
- 2 critical (критический приоритет)

### Основные источники уязвимостей:

1. **@strapi/plugin-users-permissions** - уязвимости в плагине аутентификации
2. **axios** - уязвимости в HTTP клиенте (SSRF, CSRF)
3. **yookassa** - использует устаревший пакет `request` с критической уязвимостью
4. **nodemailer** - уязвимости в email провайдере
5. **koa** - уязвимости в веб-фреймворке

## Рекомендации

### ✅ Безопасные действия:

1. **Не используйте `npm audit fix --force`** без тщательной проверки
2. **Регулярно обновляйте зависимости** вручную:
   ```bash
   npm update
   ```
3. **Следите за обновлениями Strapi**:
   ```bash
   npm outdated @strapi/strapi
   ```
4. **Проверяйте уязвимости** без автоматического исправления:
   ```bash
   npm audit
   ```

### ⚠️ Для production:

1. **Используйте reverse proxy** (nginx) для дополнительной защиты
2. **Настройте rate limiting** в Strapi
3. **Ограничьте CORS** только необходимыми доменами
4. **Используйте HTTPS** для всех соединений
5. **Регулярно обновляйте зависимости** в контролируемом режиме

### 🔒 Митигация рисков:

1. **yookassa** - рассмотрите обновление или замену на более современную библиотеку
2. **nodemailer** - следите за обновлениями, возможно потребуется обновление до версии 8.x
3. **axios** - обновление до последней версии (может потребовать изменений в коде)

## Полезные команды:

```bash
# Проверить уязвимости (без исправления)
npm audit

# Проверить устаревшие пакеты
npm outdated

# Обновить пакеты (безопасно, в пределах semver)
npm update
```
