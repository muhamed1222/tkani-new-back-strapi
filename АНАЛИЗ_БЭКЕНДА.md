## 🏗 Архитектура проекта

### Общая структура
Проект построен на **Strapi CMS 5.31.3** - современном headless CMS на Node.js. Это полноценный бэкенд для интернет-магазина тканей с REST API, админ-панелью и интеграциями.

### Технологический стек

#### Основные технологии:
- **Strapi 5.31.3** - Headless CMS
- **Node.js >= 20.0.0** - Runtime
- **React 18.3.1** - Админ-панель
- **PostgreSQL / SQLite** - База данных

#### Зависимости:
- `@strapi/strapi: ^5.31.3` - Ядро Strapi
- `@strapi/plugin-users-permissions: 5.31.3` - Управление пользователями
- `@strapi/provider-email-nodemailer: ^5.31.3` - Email отправка
- `pg: ^8.16.3` - PostgreSQL драйвер
- `better-sqlite3: ^12.4.1` - SQLite драйвер
- `nodemailer: ^7.0.11` - Email клиент
- `cloudpayments: ^6.0.1` - Платежная система
- `@sentry/node: ^10.29.0` - Мониторинг ошибок

## 🔌 API Endpoints

### Аутентификация и пользователи

#### Регистрация
- `POST /api/registration` - Регистрация нового пользователя
  - Body: `{ username, email, password, firstName, lastName, middleName, phone }`
  - Response: `{ jwt, user }`

#### Профиль
- `GET /api/profile/check-auth` - Проверка авторизации
- `PUT /api/profile` - Обновление профиля
- `DELETE /api/profile/delete-account` - Удаление аккаунта

#### Восстановление пароля
- `POST /api/forgot-password` - Запрос восстановления пароля

### Товары и каталог

#### Товары
- `GET /api/products` - Список товаров (с фильтрацией, сортировкой, пагинацией)
- `GET /api/products/:id` - Детали товара
- `POST /api/products` - Создание товара (требует авторизации)
- `PUT /api/products/:id` - Обновление товара
- `DELETE /api/products/:id` - Удаление товара

#### Категории
- `GET /api/categories` - Список категорий
- `GET /api/categories/:id` - Детали категории

#### Работы
- `GET /api/works` - Список работ
- `GET /api/works/:id` - Детали работы

#### Баннеры
- `GET /api/banners` - Список баннеров

### Корзина

- `GET /api/cart` - Получить корзину пользователя
- `POST /api/cart/add` - Добавить товар в корзину
  - Body: `{ product_id, quantity }`
- `POST /api/cart/update` - Обновить количество товара
  - Body: `{ product_id, quantity }`
- `POST /api/cart/remove` - Удалить товар из корзины
  - Body: `{ product_id }`
- `POST /api/cart/clear` - Очистить корзину
- `POST /api/cart/checkout` - Оформить заказ из корзины
  - Body: `{ customer_name, customer_email, customer_phone, delivery_method, payment_method, ... }`
  - Автоматически:
    - Создает заказ
    - Отправляет email покупателю и администратору
    - Создает уведомление
    - Очищает корзину

### Заказы

- `GET /api/orders` - Список заказов (с фильтрацией по статусу, пагинацией)
  - Query: `?filters[status]=new&pagination[page]=1&pagination[pageSize]=25`
- `GET /api/orders/:id` - Детали заказа
- `POST /api/orders` - Создание заказа
- `PUT /api/orders/:id` - Обновление заказа
- `DELETE /api/orders/:id` - Удаление заказа

**Алиасы для совместимости:**
- `/api/order` (singular) - те же endpoints

### Уведомления

- `GET /api/notifications` - Список уведомлений пользователя
- `GET /api/notifications/:id` - Детали уведомления
- `PUT /api/notifications/:id` - Отметить как прочитанное

## 🔒 Безопасность

### Реализованные меры:

1. **Аутентификация:**
   - JWT токены через `@strapi/plugin-users-permissions`
   - Срок действия токена: 7 дней
   - Автоматическая проверка авторизации на защищенных endpoints

2. **CORS:**
   - Настроен для доменов:
     - `http://localhost:5173-5175` (dev)
     - `https://centertkani.ru`
     - `https://www.centertkani.ru`
     - `https://api.centertkani.ru`
   - Credentials: enabled

3. **Валидация файлов:**
   - Middleware `file-validation.js`
   - Whitelist типов файлов
   - Проверка расширений
   - Максимальный размер: 250 MB

4. **Email безопасность:**
   - Middleware `email-security.js`
   - Валидация email адресов
   - Защита от инъекций

5. **Sentry мониторинг:**
   - Middleware для отслеживания ошибок
   - Логирование запросов и ошибок
   - Контекст пользователя

6. **Права доступа:**
   - Автоматическая выдача публичных прав на чтение для:
     - `api::product.product` (find, findOne)
     - `api::category.category` (find, findOne)
     - `api::work.work` (find, findOne)

## 🔄 Lifecycle Hooks

### Order (Заказы)

**beforeCreate:**
- Генерация уникального `order_number` (если не указан)
- Расчет `total` для каждого item (meters × price_per_meter)
- Расчет `total_price` (сумма items + delivery_price)

**beforeUpdate:**
- Пересчет `total_price` при изменении items или delivery_price
- Запрет прямого редактирования `total_price`
